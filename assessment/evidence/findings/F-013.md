# F-013 | P1 | dependency / security (accepted risk)

**Impact:** Rails 7.0.10 (from `api/Gemfile.lock`) is end-of-life — security support ended 2025-04-01 — so production runs an unpatched framework. The web also ships 3 moderate vulns in the tailwindcss/postcss chain.

**Evidence:**
- `api/Gemfile` pins `rails ~> 7.0.8`; lock resolves to 7.0.10. Rails 7.0 EOL per `rubyonrails.org` maintenance policy and `endoflife.date/rails` (security fixes ended 2025-04-01).
- `npm audit`: 3 moderate — `postcss-selector-parser < 7.1.6` via `tailwindcss 3.4.x → postcss-nested` (GHSA-rj75-hqrm-r3gf). Fix requires tailwindcss 4.x (breaking).
- Ruby 3.3.2 is in security maintenance until 2027-03-31 (acceptable, near-EOL).

**Expected:** Run a supported framework (Rails 8.x) and resolve known advisories, or formally accept the risk with an owner and upgrade path.

**Caught by:** planned — `dependency-audit` CI job (`bundle audit` + `osv-scanner` + `npm audit`).

**Status:** accepted risk (deferred). Rails upgrade is out of scope for this pass; recorded in `03-release-decision.md` with owner + expiry.
